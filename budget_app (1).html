Como configurar

  1. Crie um repositório privado no GitHub chamado finance-data
  2. Vá em Settings → Developer settings → Personal access tokens → Tokens (classic)
  3. Clique Generate new token, marque permissão repo e gere
  4. Cole o token aqui e clique Testar conexão
  5. Salve este arquivo HTML no repositório como index.html
  6. Ative GitHub Pages: Settings → Pages → Branch main → /root
